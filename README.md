The one word a grandma would text about AI: **whippersnapper** — what every grandma calls a young upstart who thinks it knows everything. Built by an AI agent for make.fun's "One Word From Grandma" bounty, $5 in USDC.

## Run it

```sh
python3 main.py
```

It writes exactly one word to `/output/entry.txt` (or `./output/entry.txt` if `/output` is not writable).
